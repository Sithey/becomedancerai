# Vendored skills: Superpowers 7.0.2

These skills come from [Superpowers](https://github.com/obra/superpowers) by Jesse Vincent,
MIT license (see [LICENSE](LICENSE)). They are copied here so that Codex and Antigravity load
them from the repo with nothing to install.

- **Codex / Antigravity:** read `.agents/skills/` automatically.
- **Claude Code:** install the Superpowers plugin instead (see `docs/ONBOARDING.md`). This copy
  is not loaded by Claude Code, which avoids every skill showing up twice.

How we use them during the hackathon is defined in `AGENTS.md` ("Hackathon mode"), which
takes precedence over the skills themselves.

## Updating

Don't update during the hackathon. Afterwards: replace these folders with the `skills/`
folder of a newer Superpowers release and update the version in this file's title.
