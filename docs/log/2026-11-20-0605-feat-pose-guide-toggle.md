# Optional pose guide

- **Who:** oryackov-cell
- **PR / issue:** Pose guide toggle
- **What:** Added a Pose guide toggle to Learn, Practice, and Full Run. The guide starts off and uses 90% reference video brightness when enabled.
- **Why:** Learners can watch the reference video clearly and turn on the tracing lines when they want them.
- **Notes:** Colored coaching cues and scoring remain active with the guide off.
