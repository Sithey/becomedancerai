# Progress log

Every PR adds **one new file** here. One file per PR means no merge conflicts on a shared log.

## File name

`YYYY-MM-DD-HHMM-<branch>.md`, with `/` in the branch name replaced by `-`.

Example: branch `fix/12-login-button` merged on Nov 19 at 14:30 →
`2026-11-19-1430-fix-12-login-button.md`

## Content

```markdown
# <Short title>

- **Who:** <your name>
- **PR / issue:** #<number>
- **What:** <what changed, in one or two sentences>
- **Why:** <the reason>
- **Notes:** <anything the next person should know, or "none">
```
