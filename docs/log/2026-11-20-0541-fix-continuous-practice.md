# Continuous Practice and Full Run

- **Who:** Ido (@idobu11-hue)
- **PR / issue:** #43
- **What:** Practice and Full Run play through missed moves and show scores and coaching tips after the session. Learners can retry a specific move at half speed.
- **Why:** Learners can finish the dance before reviewing mistakes and spending extra time on the moves they missed.
- **Notes:** A targeted retry can improve the move score. The original Full Run score is preserved.
