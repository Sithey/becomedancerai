# Count-in countdown and audio cue

- **Who:** Ido
- **PR / issue:** Count-in before moves and full run
- **What:** Added a big animated 3-2-1 visual countdown over both panels with an audible count-in (crisp Web Audio metronome beeps on 3, 2, 1) before moves start looping in Practice and before the Full run begins.
- **Why:** Prepares the dancer with an audible and visual count-in so they start moving on time with the video; keeps the video paused during countdown so nothing is falsely scored.
- **Notes:** Self-contained in `components/dance/count-in.tsx` with minimal edits to `practice-session.tsx`.
